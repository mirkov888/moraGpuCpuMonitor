# Mora GPU Monitor (aplikasi)
Tampilan monitor + OC yang sama dengan WebUI module, dibungkus jadi aplikasi (WebView + jembatan `su`).
Syarat: HP sudah root dan module **Overclock CPU + GPU V1.4** terpasang (aplikasi memakai skrip module).

Cara build tanpa Android Studio: upload folder ini ke repo GitHub, buka tab Actions > build-apk,
lalu unduh artifact `MoraGpuMonitor-debug` (app-debug.apk). Atau buka di Android Studio > Build APK.
Saat pertama dibuka, izinkan akses root di manajer root (KernelSU Next).
